# Dental AI — версия на Voximplant

Параллельная ветка проекта: голосовой слой (телефония + ASR/TTS + сценарий звонка)
живёт в облаке **Voximplant**, мозг/слоты/запись/дашборд — наш FastAPI. Основная
LiveKit-версия лежит рядом в `dental-ai-mvp/` и не тронута.

## Архитектура

```
телефон пациента ←→ Voximplant (voxengine_scenario.js: звонок, Yandex ASR/TTS, barge-in)
                          ↕ HTTP (на каждый ход диалога)
                  наш server.py (LLM OpenRouter + слоты + запись + дашборд)
```

Что даёт Voximplant по сравнению с LiveKit-версией: телефонные номера РФ и
исходящие звонки из коробки (не нужен SIP-оператор с ЭЦП и свой медиасервер),
маркировка вызовов, запись разговоров. Ценой: голосовой сценарий на их движке
и поминутная плата платформе (~4–5 ₽/мин всё вместе, см. расчёт в
`../docs/product-and-costs.md`).

## Файлы

| Файл | Роль |
|---|---|
| `voxengine_scenario.js` | сценарий звонка — **загружается в облако Voximplant** |
| `server.py` | наш бэкенд: мозг (LLM), слоты, запись, дашборд, обработка ходов диалога |
| `vox_dispatch.py` | запуск звонка через Management API (StartScenarios) |
| `db.py`, `brain.py` | общие с основной версией (копии): БД и системный промпт |
| `web/` | лендинг + дашборд (без браузерного голоса — звонок настоящий) |

## Настройка (по шагам)

### 1. Аккаунт Voximplant
1. Регистрация: manage.voximplant.ru (продукт **Platform**, не Kit).
2. Пополните баланс (рублями). На демо хватит нескольких сотен рублей.
3. **Номер**: Числа/Numbers → арендуйте городской номер (~$4–7/мес) — это ваш Caller ID.
   Либо подтвердите собственный номер как Caller ID (verify).

### 2. Приложение и сценарий
1. Applications → **Create application** (например, `dental`).
2. Внутри приложения → Scenarios → **создайте сценарий** и вставьте содержимое
   `voxengine_scenario.js`.
   ⚠️ Проверьте автодополнением в их IDE два имени: голос
   (`VoiceList.Yandex.Neural.ru_RU_alena`) и модель распознавания
   (`ASRModelList.Yandex.general`) — названия периодически меняются.
3. Routing → **создайте правило (Rule)**, привяжите к нему сценарий.
   Запишите **rule_id** (виден в URL/списке правил).

### 3. Ключи Management API
Настройки аккаунта → API keys: возьмите **account_id** и создайте **api_key**.

### 4. Бэкенд
```bash
pip install -r requirements.txt
cp .env.example .env    # заполните все VOX_*, OPENROUTER_API_KEY
# бэкенд должен быть доступен из интернета:
ngrok http 8000         # полученный https-URL -> PUBLIC_BACKEND_URL в .env
set -a; source .env; set +a
uvicorn server:app --reload --port 8000
```

### 5. Прогон
Откройте лендинг `http://127.0.0.1:8000`, оставьте заявку со своим номером —
телефон зазвонит, Алёна (Yandex-голос) поздоровается, уточнит и запишет; на
дашборде `/dashboard` заявка станет «записан», окно недели закрасится.
Кнопка «📞 Перезвонить» на дашборде повторяет звонок по заявке.

## Отладка
- Логи сценария: панель Voximplant → приложение → Calls/Logs (Logger.write пишет туда).
- Если звонок не стартует: проверьте баланс, rule_id, что номер разрешён как Caller ID.
- Если агент молчит: смотрите, дотягивается ли сценарий до PUBLIC_BACKEND_URL (ngrok жив?).
- Текстовый fallback на дашборде работает без Voximplant вообще (только OPENROUTER_API_KEY).

## Что осталось общим с LiveKit-версией
`db.py` и `brain.py` — копии из `dental-ai-mvp/`. Меняете промпт/логику записи —
меняйте в обеих папках (или вынесите в общий пакет, когда выберете основную ветку).
