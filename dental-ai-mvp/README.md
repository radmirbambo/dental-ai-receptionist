# Dental AI — исходящий AI-оператор · MVP для инвест-демо

Демо показывает ровно обещание из питч-дека (шаги 1→2): **лид оставил заявку → AI
перезвонил → записал на первичный осмотр**, и всё это видно живьём на дашборде.

## Что это делает

1. Инвестор открывает **лендинг** (`/`), оставляет заявку (имя + телефон).
2. Backend сохраняет лид и **запускает исходящий звонок** через LiveKit + SIP.
3. **Голосовой агент** (свой пайплайн: Deepgram STT → OpenRouter LLM → ElevenLabs TTS)
   звонит на телефон, говорит по-русски, уточняет запрос, предлагает время, записывает.
4. **Дашборд** (`/dashboard`) в реальном времени показывает: заявка → «звоним» →
   «записан», плюс календарь записей и конверсию.
5. **Fallback:** если телефония не готова — кнопка «Позвонить текстом» на дашборде
   ведёт тот же диалог печатью. Демо не сорвётся никогда.

## Файлы

| Файл | Роль |
|---|---|
| `db.py` | БД: лиды (статус дозвона) + записи. SQLite → легко на Postgres |
| `brain.py` | системный промпт + текстовый режим агента (и fallback) |
| `caller_agent.py` | **голосовой агент LiveKit**, дозвон по SIP (ядро) |
| `dispatch.py` | запуск звонка (создание LiveKit dispatch) |
| `server.py` | FastAPI: лендинг, дашборд, приём заявок, текст-fallback |
| `web/index.html` | лендинг заявки |
| `web/dashboard.html` | живой дашборд оператора |

## Аккаунты (завести заранее — это половина времени)

1. **OpenRouter** — ключ LLM. https://openrouter.ai/keys
2. **LiveKit Cloud** — бесплатный проект. https://cloud.livekit.io → возьми `LIVEKIT_URL`, `API_KEY`, `API_SECRET`.
3. **Deepgram** — STT (даёт $200 кредитов). https://deepgram.com
4. **ElevenLabs** — TTS, выбери русский голос, скопируй его `voice_id`. https://elevenlabs.io
5. **SIP-провайдер с исходящими на РФ** — **Novofon** (бывш. Zadarma) или **Zadarma**:
   нужен SIP-логин/пароль/хост и разрешённые исходящие звонки на мобильные РФ + баланс.

## План на 2 дня

**День 1 — «мозг» и экран (низкий риск, делается точно).**
- Утро: завести все аккаунты, `pip install -r requirements.txt`, заполнить `.env`.
- День: поднять `server.py`, проверить лендинг + дашборд + **текстовый fallback** (работает без телефонии — нужен только OpenRouter). На этом этапе демо уже можно показывать «на экране».
- Вечер: отшлифовать системный промпт в `brain.py` под ваши скрипты (гигиена/лечение/имплантация), прогнать 10 диалогов, поправить формулировки.

**День 2 — реальный голосовой звонок (рисковая часть).**
- Утро: настроить исходящий SIP-транк LiveKit ↔ Novofon (шаг 3 ниже). Это главный узел риска — заложите на него запас.
- День: запустить `caller_agent.py`, позвонить самому себе, отладить язык/голос/латентность/подтверждение слота.
- Вечер: прогнать полный сценарий «заявка → звонок → запись» несколько раз, записать видео-бэкап на случай проблем с сетью у инвестора.

## Настройка и запуск

### 1. Установка
```bash
pip install -r requirements.txt
cp .env.example .env        # заполни ключи
export $(grep -v '^#' .env | xargs)
```

### 2. Backend (лендинг + дашборд + fallback)
```bash
uvicorn server:app --reload --port 8000
```
Открой http://127.0.0.1:8000 (заявка) и http://127.0.0.1:8000/dashboard.
Уже сейчас можно оставить заявку и «позвонить текстом» — голос не нужен.

### 2b. Голосовое демо в браузере (без SIP, без оплаты) — основной путь

Реальный звонок голосом через микрофон, без телефонии. Нужен LiveKit + голос-ключи,
НЕ нужен SIP-транк. Это то, что показываем инвестору, пока телефония не подключена.

```bash
# поставить голосового агента (один раз)
pip install "livekit-agents[deepgram,elevenlabs,openai,silero,turn-detector]" livekit-api

# запустить воркера (отдельное окно; сервер из шага 2 тоже работает)
export $(grep -v '^#' .env | xargs)
python caller_agent.py dev
```

Теперь на лендинге оставьте заявку → кнопка **«🎙️ Поговорить с AI-оператором»**
(или на дашборде у заявки кнопка **«Голосом»**). Откроется страница `/voice`,
разрешите микрофон — агент заговорит первым, запишет на осмотр, статус на дашборде
станет «записан». Для браузера нужны в `.env`: `LIVEKIT_URL/API_KEY/API_SECRET`,
`OPENROUTER_API_KEY`, `DEEPGRAM_API_KEY`, `ELEVENLABS_API_KEY`, `ELEVEN_VOICE_ID`.
`SIP_OUTBOUND_TRUNK_ID` можно оставить пустым.

### 3. Исходящий SIP-транк (для реального ТЕЛЕФОННОГО звонка — когда появится транк)
Один раз настраивается связка LiveKit → провайдер. Через LiveKit CLI (`lk`):

```bash
# файл outbound_trunk.json — данные твоего Novofon/Zadarma SIP:
# {
#   "trunk": {
#     "name": "novofon-out",
#     "address": "sip.novofon.com",          # SIP-хост провайдера
#     "numbers": ["ВАШ_НОМЕР"],              # ваш городской/SIP-номер (Caller ID)
#     "auth_username": "SIP_LOGIN",
#     "auth_password": "SIP_PASSWORD"
#   }
# }
lk sip outbound create outbound_trunk.json
# в ответ придёт ST_xxxx — впиши его в .env как SIP_OUTBOUND_TRUNK_ID
```
Подробности и точные поля: LiveKit → Telephony → Making calls → Outbound trunk.

### 4. Голосовой воркер
```bash
python caller_agent.py dev
```
Теперь заявка на лендинге запускает настоящий звонок на указанный телефон.

## Сценарий демо (5 минут перед инвестором)

1. Открой **дашборд** на проекторе — он пустой, обновляется живьём.
2. Дай инвестору **лендинг** на телефоне/ноутбуке. Пусть впишет **своё имя и свой номер**.
3. Через секунду на дашборде появляется заявка → статус меняется на **«звоним»**.
4. **Телефон инвестора звонит.** Он берёт трубку — русскоязычный AI здоровается,
   уточняет, предлагает время, записывает на осмотр.
5. На дашборде статус → **«записан»**, справа появляется запись в календаре, конверсия растёт.
6. Панч: «Это заняло 40 секунд и ~5 ₽. Живой оператор пропустил бы этот звонок вечером».

**Если сеть/телефония подводит:** тот же поток, но на шаге 4 жмёшь на заявке
**«Позвонить текстом»** и ведёшь диалог печатью — логика записи та же, дашборд так же
обновляется. Всегда держи это как план Б (плюс записанное видео удачного звонка).

## Риски и как их снять

- **SIP на РФ — главный риск.** Настрой и проверь транк в первой половине дня 2, не в последний час. Если не поднимается — демо идёт через текстовый fallback + видео реального звонка.
- **Оплата зарубежных сервисов из РФ.** Deepgram/ElevenLabs/OpenRouter — заведи оплату заранее. Альтернатива под РФ: Yandex SpeechKit (STT+TTS, рубли) — но потребует своего плагина, на 2 дня рискованно; оставь на потом.
- **Латентность/язык.** Проверь, что Deepgram стоит `language="ru"`, а голос ElevenLabs — русский. Держи фразы агента короткими (уже заложено в промпте).
- **Согласие на запись разговора** (152-ФЗ) — для демо на своих номерах ок; в проде добавь фразу-уведомление в начало звонка.

## Стоимость одного демо-звонка
~$0.10–0.20 за минуту (Deepgram + LLM + ElevenLabs + SIP). Десяток тестовых прогонов — пара долларов.
